# Tarun Siddhartha M — Executive Digital CV v3

This version is designed as a senior/middle-management financial-services profile rather than a developer portfolio.

Files:
- index.html
- style.css
- script.js
- README.md

Optional:
- Add `resume.pdf` to the repository root for the Download CV buttons.

Deployment:
1. Replace index.html, style.css and script.js in `sid-1608/sid.github.io`.
2. Commit and push.
3. Refresh the GitHub Pages URL with a hard refresh if an old stylesheet is cached.

Theme:
- Light mode is the default.
- Dark mode is controlled by the circular button in the top-right.
- The selected theme is stored in localStorage as `cv-theme`.
- Unlike the previous version, there is no conflicting theme initialization; the toggle controls the body class directly.
